# Rings Watch Face

Wear OS 用のウォッチフェイスです。外側から「秒・分・時・週の予定・曜日」の5本の同心円リングで時間を表示します。

Watch Face Format (WFF) で作り、Google Play で公開する予定です。

## 構成

- `app/src/main/res/raw/watchface.xml` … ウォッチフェイス本体(WFF v2、Wear OS 5 以降)
- `mobile/` … スマホアプリ。7日先までの予定の開始・終了時刻、休みの日、スマホの電池残量、切り替え方を時計に送ります(予定のタイトルは送りません)
- `wear/` … 時計アプリ。受け取った予定を数値にまとめ、コンプリケーションとして文字盤に渡します。数値の詰め方は `wear/src/main/java/io/github/satoshimiyasaka/rings/Rings.kt` に書いています
- `tools/generate_watchface.py` … 上の XML と画像を生成するスクリプト。リングの寸法・色・祝日はここで変更します
- 祝日は 2026〜2030 年の日本の祝日を書き込んでいます。`HOLIDAY_YEARS` を延ばして再生成してください

```sh
pip install pillow
python3 tools/generate_watchface.py
./gradlew assembleDebug
```

## いまの版でできること

- 秒・分・時・曜日の4本のリングを白い印で指す。曜日は週の予定と曜日リングをまたぐ線(時は12時間で1周)
- 曜日リングの日曜・祝日をピンク、土曜を青で表示。祝日は7日前から色が付きます
- 中央に日付、天気(気温と天気名)、次の予定(カレンダーのコンプリケーション)
- 常時表示では秒の印を消し、リングを暗くします。目盛りは暗くしません

文字盤の編集画面で選べるもの:

- 目盛り:リングの切れ目を明るい色にする。「秒と曜日」(初期値)・「すべてのリング」・「なし」から選ぶ
- 目盛りの色:白・赤・青・黄・緑・灰色
- 秒・分・時の印:内向き(三角)・外向き(三角)・丸・線から選ぶ(初期値は秒と分が内向き、時が丸)
- 秒のリングに表示:なし・歩数(目標に対する割合)・時計の電池・スマホの電池。12時の位置から割合の分だけリングが光ります。スマホの電池は連携アプリが必要で、1時間ごとの送信時の値です(3時間届かないと消えます)

連携アプリを入れると、次の表示が加わります。

- 時リング:予定がある30分区間が光る
- 分リング:予定が1分単位で光る
- 時と分のリングの切り替え方はスマホアプリで選べます
  - 1周したら切り替える(初期値):時リングは今の12時間(0〜12時または12〜24時)を出し、0時と12時に次の12時間へ切り替わる。分リングは今の1時間を出し、毎正時に切り替わる
  - 5分ごとに切り替える:針が過ぎた区間に次の周の予定を出す。5分ごとに更新する
- 週の予定リング:今日から6日後までの予定がある2時間区間が光る。0時に1日ずつ切り替わる
- 曜日リング:名前に「休み・休暇・有給・休日」などを含む終日の予定がある日を、祝日と同じピンクにする(言葉はスマホアプリで変更可)。それ以外の終日の予定(旅行やキャンプなど)がある日は緑にする
- スマホアプリで、時計に送るカレンダーを選べます(ゴミの日などのカレンダーを外せます)

入れる順番は、スマホアプリ、時計アプリ、文字盤の順です。文字盤を先に入れていた場合は、時計アプリを入れた後に文字盤を選び直してください。

## 開発メモ

- 予定を渡すデータ用の枠は、文字盤の編集画面に出ない固定の枠にしています。
- クローズドテストを始めたら、データ用の枠は追加・削除・並べ替えをしないでください。時計は文字盤を追加した時点の並び順で各枠のデータ元を覚えるため、並べ替えると別の枠のデータが入り、後から足した枠はアップデートした人の時計では文字盤を追加し直すまで空のままになります(PR #5 の実機確認で判明)。
